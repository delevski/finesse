05

What the skill enforces

Eight hard rules bind every component an agent touches. The references carry copy-paste patterns for each.

States first

Pending, error, empty, success - built before the happy path. Every submit guards double clicks and offers retry.

Tokens only

No hex literals, no one-off grays. Semantic theme tokens, a real radius and elevation scale, dark mode re-tuned rather than inverted.

Motion with intent

Staggered entrances, layout transitions, press feedback - transform and opacity only, with reduced-motion fallbacks.

RTL native

Logical properties, mirrored directional icons, LTR islands for numbers, Hebrew typography - from the first commit.
